# RFCs

An RFC records a design decision before it is implemented: what we build, why, and what we chose not to do.

## Process

- **File name:** `NNNN-kebab-title.md`, using the next free number. Start from [template.md](template.md).
- **Status:** `Draft → Accepted → Implemented`. An RFC replaced by a later one becomes `Superseded`, with a link to its successor.
- **Cadence:** one RFC at a time. Write it, get it accepted, implement it, then write the next, so each RFC learns from the previous implementation.
- **Acceptance:** the PM accepts RFCs.
- **Plans:** once an RFC is accepted, its implementation plan goes to `docs/plans/`.
